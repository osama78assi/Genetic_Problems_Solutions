# Introduction
This code is written in python and Django as normal API. It uses both `Genetic Algorithms` and `Dynamic Programming` to solve two different problems

There is many trucks which want to take the goods and distribute them over warehouses or customers. The first part is `Knapsack Problem` and it's solved using both `Dynamic Programming` and `Genetic`. While the second part is `Travelling Salesman Problem` which is solved only with `Genetic`. There is a part also that is required to find the shortest path which I used both `Genetic` and `A star`
